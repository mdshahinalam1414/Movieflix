# রিল আর্কাইভ — সেটআপ গাইড

তিনটা ফাইল আছে:
- `index.html` — পুরো সাইট (HTML + CSS + JS একসাথে)
- `Code.gs` — Google Apps Script ব্যাকএন্ড (Google Sheet-কে API বানায়)
- এই README

## ধাপ ১ — Google Sheet বানাও
1. নতুন একটা Google Sheet খোলো।
2. ট্যাবের নাম দাও `Movies`।
3. প্রথম সারিতে (Row 1) এই হেডারগুলো বসাও, ঠিক এই ক্রমে:
   ```
   Timestamp | Name | Year | Country | Language | Category | WatchLink | DownloadLink | Poster
   ```
4. Sheet-এর URL থেকে Sheet ID কপি করো (URL-এর `/d/` আর `/edit`-এর মাঝের অংশটুকু)।

## ধাপ ২ — Apps Script বসাও
1. Sheet-এর মেনু থেকে **Extensions → Apps Script**।
2. যা আছে সব মুছে `Code.gs` ফাইলের কোড পেস্ট করো।
3. কোডের উপরের দিকে `SHEET_ID` এর জায়গায় নিজের Sheet ID বসাও।
4. বাম পাশে **Project Settings (গিয়ার আইকন) → Script Properties → Add script property**:
   - Property: `ADMIN_PASSWORD`
   - Value: তোমার পছন্দের পাসওয়ার্ড (এটাই সাইটে অ্যাডমিন লগইনের পাসওয়ার্ড)
5. উপরে **Deploy → New deployment**।
   - Type বাছো: **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - Deploy করো, Google পারমিশন চাইবে — অনুমতি দাও।
6. Deploy হওয়ার পর একটা URL পাবে (`https://script.google.com/macros/s/.../exec`) — এটা কপি করে রাখো।

## ধাপ ৩ — index.html-এ API URL বসাও
`index.html` ফাইলে খুঁজে বের করো:
```js
const API_URL = "PASTE_YOUR_APPS_SCRIPT_WEB_APP_URL_HERE";
```
এখানে ধাপ ২-এ পাওয়া URL বসিয়ে সেভ করো।

## ধাপ ৪ — GitHub Pages-এ পাবলিশ করো
1. GitHub-এ একটা নতুন রিপোজিটরি বানাও।
2. `index.html` ফাইলটা আপলোড করো (root-এ, চাইলে সাথে `Code.gs` আর `README.md`-ও রাখতে পারো রেফারেন্সের জন্য)।
3. রিপোর **Settings → Pages** এ যাও।
4. Source হিসেবে `main` ব্র্যাঞ্চ, ফোল্ডার `/root` বাছো, Save করো।
5. কিছুক্ষণ পর `https://<username>.github.io/<repo-name>/` লিংকে সাইট লাইভ হয়ে যাবে।

## ব্যবহার
- সাইটে ঢুকে **"অ্যাডমিন"** বাটনে ক্লিক করো, পাসওয়ার্ড দাও।
- লগইন হলে ফর্ম আসবে — Name, Year, Country, Language, Category, Watch লিংক, Download লিংক (আর চাইলে পোস্টার ছবির URL) দিয়ে সংরক্ষণ করো।
- ডেটা সাথে সাথে Google Sheet-এ যোগ হবে এবং সাইটে দেখা যাবে।
- দর্শকরা উপরের সার্চ বক্স আর ক্যাটাগরি চিপ (মুভি/সিরিজ/নাটক) দিয়ে ফিল্টার করতে পারবে।

## গুরুত্বপূর্ণ সীমাবদ্ধতা (সততার সাথে জানানো দরকার)
- **এমবেড প্লেব্যাক নির্ভর করে হোস্টিং সাইটের উপর।** অনেক ফাইল-শেয়ারিং সার্ভিস (যেমন Terabox) সরাসরি `iframe`-এ প্লে হতে দেয় না (X-Frame-Options ব্লক করে)। এই কারণে সাইটে "নতুন ট্যাবে দেখুন" বাটনও রাখা হয়েছে ফলব্যাক হিসেবে। সরাসরি `.mp4`/`.webm` লিংক দিলে সাইটেই HTML5 প্লেয়ারে চলবে।
- **অ্যাডমিন পাসওয়ার্ড সার্ভার-সাইডে (Apps Script-এ) যাচাই হয়**, তাই ব্রাউজারের সোর্স কোড দেখে কেউ পাসওয়ার্ড বের করতে পারবে না। তবে এটা এন্টারপ্রাইজ-গ্রেড নিরাপত্তা না — ব্যক্তিগত/ছোট প্রজেক্টের জন্য যথেষ্ট।
- Google Apps Script Web App ফ্রি টিয়ারে কিছু ব্যবহারের সীমা (quota) আছে; অনেক বেশি ভিজিটর হলে সেটা মাথায় রেখো।
- **শুধু এমন কনটেন্ট যোগ করো যেটার তোমার নিজের অধিকার আছে বা যেটা বৈধভাবে শেয়ার/ডিস্ট্রিবিউট করার অনুমতি আছে।** কপিরাইটেড কনটেন্ট (তৃতীয় পক্ষের মুভি/সিরিজ) অনুমতি ছাড়া হোস্ট বা শেয়ার করলে GitHub, Google, এবং কনটেন্ট মালিকদের পক্ষ থেকে টেকডাউন বা অ্যাকাউন্ট সাসপেনশনের ঝুঁকি থাকে।
